# Sources

Read this when a method or rule is questioned.

| Method or rule | Source | What it gives this skill |
| --- | --- | --- |
| Show, then ask | Nielsen Norman Group, "Recognition rather than recall" (10 usability heuristics) | People pick from what they see far more reliably than they produce from memory |
| One rung down | Reynolds and Gutman (1988), "Laddering theory, method, analysis, and interpretation", Journal of Advertising Research | Asking why an attribute matters reaches the reason (consequence, value) behind it; we stop after one rung |
| Two alike, one different | Kelly (1955), The Psychology of Personal Constructs, repertory grid triads | Comparing three elements makes people name the dimensions they really judge by |
| Alternatives in the checklist | Krosnick (1991), "Response strategies for coping with the cognitive demands of attitude measures in surveys" (satisficing, acquiescence) | People agree and shorten answers when tired; a concrete alternative turns agreement into a choice |
| Fewer questions | Same, and survey-length research generally | Effort per question rises through a survey; every question must earn its place |
| The floor | WCAG 2.2 (contrast, focus, target size, reduced motion); MDN `prefers-reduced-motion`; web.dev Core Web Vitals | Rules no taste relaxes |
| Values for motion feel | Common easing curves (Material standard easing, ease-out-quint and back curves) | Starting values the person never has to name |
| Skill format | Agent Skills format (name, description, SKILL.md, references one level deep) | What check-skill.mjs enforces |

When a source changes, update the rule, this table and the changelog in `README.md` together.
