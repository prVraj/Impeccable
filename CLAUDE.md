# Impeccable

Before you write or change any Install prompt or Blend prompt (lib/prompts.ts), for a component, section or animation (skills have no prompts), read and follow `.agents/skills/impeccable-prompts/SKILL.md`. Run its audit before you call the work done.

Before you commit, give push commands, or call work ready to ship, run `.agents/skills/pre-push-check/SKILL.md`: security review, README kept in step with the site, build, and a look in light and dark on desktop and phone. Never run `git push` yourself; the person pushes.

Before you create, rewrite or trim any skill (`.agents/skills/` or `skills/`), or turn notes into one, read and follow `.agents/skills/impeccable-writing-skills/SKILL.md`. Run its audit before you call the work done.

Before you write or change any item's description (the line under the title on its docs page, its meta description, or its `blurb` in lib/site.ts), read and follow `.agents/skills/impeccable-descriptions/SKILL.md`. Two lines at most: what it does, where to use it, and the best way to use it. Run its audit before you call the work done.
